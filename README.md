# sLLM
A framework to mitigate hallucinations when orchestrating Small Large Language Models (sLLM). You can use any model which you prefer. 
## Used model to create
- We have used Microsoft model Phi3.5:3.8b for creating this project.

## SimpleQA evaluation

For running the upstream SimpleQA evaluator with Ollama, see [docs/simpleqa_eval.md](docs/simpleqa_eval.md). The official grader source and MIT license are recorded under `git_ripo/simple_evals/`; the adapter saves aggregate results under `results/simpleqa/`.
